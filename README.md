# 梦喻解梦 - 纯前端静态 AI 解梦网站

## 项目简介

梦喻解梦是一款纯前端静态AI解梦网站，全程无后端、无服务器、不调用任何第三方API、无需网络接口、纯本地运行，适配部署在 GitHub Pages。

## 技术栈

- HTML5
- Tailwind CSS CDN
- 原生JavaScript
- 本地存储 (localStorage)

## 项目结构

```
├── index.html          # 首页 - 解梦主页
├── history.html        # 梦境日记页面
├── dictionary.html     # 梦境词典页面
├── css/
│   └── style.css       # 自定义样式
├── js/
│   ├── data.js         # 内置梦境词库数据
│   └── main.js         # 主脚本逻辑
└── README.md           # 项目说明文档
```

## 功能特点

### 1. 首页 (index.html)
- 文本框手动输入自己的梦境
- 自带常见梦境快捷标签：被追赶、飞翔、坠落、考试、蛇、水、已故亲人、噩梦、动物、迷路等
- 点击【开始解梦】，通过内置本地梦境词库自动匹配解析
- 解析内容包含：传统周公解梦、寓意解读、心理暗示、生活暗示
- 支持保存本次解梦记录

### 2. 梦境日记 (history.html)
- 使用 localStorage 本地储存所有解梦记录
- 展示时间、梦境内容、解梦结果
- 支持单条删除、清空全部记录

### 3. 梦境词典 (dictionary.html)
- 内置海量常见梦境大全
- 分类展示：人物、动物、自然、场景、物品、行为
- 点击词条直接查看完整解梦含义

## 设计风格

- 神秘古风+暗黑静谧配色
- 深紫、藏青、黑色为主
- 毛玻璃卡片、柔和渐变、简约文艺
- 适配手机和电脑端

## 使用方法

1. 直接在浏览器中打开 `index.html` 文件即可使用
2. 或部署到 GitHub Pages 上访问

## 本地运行

1. 克隆或下载项目到本地
2. 双击 `index.html` 文件即可在浏览器中打开
3. 无需安装任何依赖，纯静态运行

## 数据管理

- 所有梦境词库数据存储在 `js/data.js` 文件中
- 可根据需要自行修改或扩展梦境词条
- 解梦记录存储在浏览器的 localStorage 中，仅在本地保存

## 注意事项

- 本项目为纯前端静态网站，所有数据均存储在本地
- 不调用任何外部API，无需网络连接即可使用
- 解梦结果仅供参考，不构成专业建议

## 部署到 GitHub Pages

1. 将项目上传到 GitHub 仓库
2. 在仓库设置中开启 GitHub Pages
3. 选择 `main` 分支作为源
4. 访问生成的 GitHub Pages URL 即可
